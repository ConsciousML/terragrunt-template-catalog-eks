# Local Development Environment

The `dev` environment, for iterating on catalog changes locally before promoting them to `staging` and `prod` in the [live repository](https://github.com/ConsciousML/terragrunt-template-live-eks).

- [Deploy and destroy the `dev` EKS stack](https://eks-forge.readthedocs.io/latest/docs/quickstart/deployment/)
- [The `.hcl` files this environment reads](https://eks-forge.readthedocs.io/latest/docs/reference/hcl_configuration/)
