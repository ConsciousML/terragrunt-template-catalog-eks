# Claude Code — Project Guide

## What This Repo Is

A **Terragrunt catalog** of reusable IaC components for EKS on AWS.
This is the **catalog** (building blocks), not live infrastructure. Deployments live in the separate `terragrunt-template-live-eks` repo.

## Never Read

Do not read or traverse `.terraform*` or `.terragrunt*` directories.

## Architecture

```
modules/ → units/ → pipelines/examples/stacks/
```

- `modules/`: Terraform modules that declare AWS resources
- `units/`: Terragrunt wrappers around modules, one per component
- `pipelines/examples/stacks/`: Executable stack configs for testing
- `pipelines/bootstrap/`: One-time setup pipelines (run before any stack)
- `pipelines/root.hcl`: S3 backend + AWS provider (inherited by all units)
- `pipelines/version.hcl`: Resolves current git branch → used as `?ref=` in all module sources

## What the EKS Stack Deploys

Entry point: `pipelines/examples/stacks/eks/terragrunt.stack.hcl`

A VPC is created and an EKS cluster is deployed inside it. An ACM certificate is issued for the subdomain using DNS validation against a public Route53 hosted zone (created by the `setup_dns` bootstrap). A matching private Route53 hosted zone is created and associated with the VPC. The AWS Load Balancer Controller runs in the cluster and provisions an internal ALB. ExternalDNS watches ingress resources and writes A records to the private zone, so the domain resolves to the ALB only from within the VPC. ArgoCD is deployed via Helm with an ALB ingress using the ACM certificate. The Tailscale operator is deployed to join the cluster to the Tailnet, enabling access to internal tools (ArgoCD, etc.) over the VPN.

## Bootstrap Pipelines (run once before deploying the EKS stack)

- `pipelines/bootstrap/enable_tg_github_actions/`: OIDC + IAM role for GitHub Actions CI
- `pipelines/bootstrap/setup_dns/`: Public Route53 hosted zone per environment — outputs NS records to delegate at your registrar
- `pipelines/bootstrap/tailscale/`: Tailscale ACL policy + OAuth client credentials

## Conventions

- Never create `README.md` files in `modules/` — auto-generated by `terraform-docs` in CI from `header.md` + `footer.md`.
- All resources are prefixed with `{environment}-` to avoid naming collisions.
